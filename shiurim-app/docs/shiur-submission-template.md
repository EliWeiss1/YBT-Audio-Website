To submit a shiur, forward the Zoom "Recording is now available" email to:
  shiurim@[YOUR_DOMAIN]

Add the following lines at the very top of the forwarded email body,
BEFORE the "---------- Forwarded message ---------" line:

  Line 1: Title: <shiur title>
  Line 2: Rabbi: <rabbi name>     ← omit this line if you always submit only your own shiurim
  Line 3: Description: <optional one-line description>

Example:

  Title: Bava Kamma 34a — Damages for Fire
  Rabbi: Rabbi Weiss
  Description: Shiur on the halacha of aish mamono

  ---------- Forwarded message ---------
  From: no-reply@zoom.us
  ...

Notes:
- The "Rabbi:" line is optional for rebbeim in the known-sender dictionary
- If omitted and your email is not recognized, the shiur will be flagged for review
- Description is always optional
- Do not edit any other part of the forwarded email

Multiple recordings in one shiur
--------------------------------
Sometimes a Zoom share link holds more than one recording — e.g. you stopped and
restarted recording in the middle (the player shows "Total 2 Recordings"). Tell us
what to do by adding ONE extra line after the description:

  merge     ← the recordings are one shiur; we'll join them into a single audio file
  separate  ← the recordings are separate shiurim (see below)

MERGE example (accidental stop/restart → one shiur):

  Bava Kamma 34a — Damages for Fire
  Rabbi Weiss
  Shiur on the halacha of aish mamono
  merge

SEPARATE example (two shiurim in one session). Line 1 is the FIRST shiur's title;
put each additional shiur's title on its own line after "separate":

  Bava Kamma 12a
  Rabbi Weiss
  separate
  Bava Kamma 12b

  → creates two shiurim: "Bava Kamma 12a" and "Bava Kamma 12b"

- If a share has multiple recordings and you write neither word, we assume an
  accidental stop/restart and MERGE them into one shiur (and email the admin so it
  can be double-checked).
- "merge"/"separate" must be on their own line, spelled exactly (case doesn't matter).
