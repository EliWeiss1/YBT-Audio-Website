To submit a shiur, forward the Zoom "Recording is now available" email to:
  shiurim@[YOUR_DOMAIN]

Add the following lines at the very top of the forwarded email body,
BEFORE the "---------- Forwarded message ---------" line:

  Line 1: Title: <shiur title>
  Line 2: Rabbi: <rabbi name>     ← omit this line if you always submit only your own shiurim
  Line 3: Description: <optional one-line description>

Example:

  Title: Bava Kamma 34a — Damages for Fire
  Rabbi: Rabbi Weiss
  Description: Shiur on the halacha of aish mamono

  ---------- Forwarded message ---------
  From: no-reply@zoom.us
  ...

Notes:
- The "Rabbi:" line is optional for rebbeim in the known-sender dictionary
- If omitted and your email is not recognized, the shiur will be flagged for review
- Description is always optional
- Do not edit any other part of the forwarded email
